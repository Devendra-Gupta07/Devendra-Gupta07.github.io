Featured project.

Wireless Text Display Using Bluetooth and Arduino Uno

Arduino Uno HC-05 Bluetooth 16×2 I²C LCD Bluetooth + I²C
Source Code
HELLO FROM MY PHONE • TEXT SENT OVER BLUETOOTH • SCROLLING FOR READABILITY •   

Mobile → HC-05 Bluetooth → Arduino Uno → 16×2 LCD

Built a wireless text display system using Arduino Uno, HC-05 Bluetooth, and a 16×2 I²C LCD. The system receives text from a mobile phone via Bluetooth and displays it on the LCD, with automatic scrolling for longer messages.

Key Features

  • Wireless text transmission
  • Automatic scrolling
  • Reduced wiring using I²C
